## 🏮 About
> [!WARNING]
> Don’t blindly use my settings unless you understand what they entail. Use at your own risk!

These are the configuration files I use in my daily life. I hope they can help you as well!

Programs' configuration files that you will find in this repository:

| Type               | Name         |
| ------------------ | -------------|
| OS                 | Gentoo Linux |
| WM                 | Niri         |
| Terminal           | Kitty        |
| Shell              | Zsh          |
| Launcher           | Rofi         |
| Top Bar            | Quickshell   |
| Text Editor        | Neovim       |
| ZSH Prompt         | Starship     |
| ZSH Plugin Manager | Zinit        |
| File Manager       | Thunar       |
| Video Player       | mpv          |

## 💾 Installation
### Dotfiles
Quick install:
```sh
git clone https://codeberg.org/ErnstBecker/dotfiles && cd dotfiles && stow .
```
